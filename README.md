# Kiapo

Kumbukumbu binafsi ya Herman Onesmo Sade — tovuti ya kibinafsi yenye hati, historia, na app ya simu.

> ⚠️ **Muhimu:** Ukurasa huu SI tovuti ya Serikali wala Mahakama. Ni matumizi binafsi tu. Hati zilizomo hazijathibitishwa na Wakili wala Mahakama.

## Muundo wa Faili

| Faili | Maelezo |
|---|---|
| `index.html` | Ukurasa wa mwanzo (landing page) — viungo vya hati zote + sehemu ya kupakua app |
| `style.css` | Mtindo (CSS) wa ukurasa wa `index.html` |
| `mahusiano.html` | Historia ya mahusiano na watoto |
| `historia ya maisha ya herman.html` | Historia fupi ya maisha ya Herman Sade |
| `ardhi.html` | Maelezo ya umiliki wa ardhi na nyumba |
| `ushahidi wa sauti.html` | Ushahidi wa sauti |
| `SADE🇹🇿.apk` | App ya Android — inapakuliwa moja kwa moja kutoka `index.html` |

## Jinsi Inavyofanya Kazi

- Ukurasa wa mwanzo (`index.html`) hauna taarifa za siri — ni viungo tu.
- Hati ya Kiapo inafunguliwa kwa namba ya siri (imewekwa ndani ya `index.html`). Hii si ulinzi wa kweli — mtu yeyote anayefungua "View Page Source" anaweza kuiona.
- Faili zote (`index.html`, `style.css`, kurasa nyingine za `.html`, na `.apk`) lazima ziwe kwenye **folda moja** kwenye repo ili viungo vifanye kazi.

## Kusakinisha App (SADE🇹🇿.apk)

1. Fungua `index.html` kwenye simu ya Android.
2. Bonyeza "Pakua Sasa (.apk)" chini ya ukurasa.
3. Ukiombwa, ruhusu "Install from unknown sources" kwenye mipangilio ya simu.
4. Fungua faili lililopakuliwa ili kukamilisha usakinishaji.

## Onyo la Faragha

Tovuti hii inatumia GitHub Pages ambayo ni ya umma. Usiweke taarifa za siri za kweli (namba za siri zenye ulinzi halisi, taarifa za benki, n.k.) ukitegemea zitabaki faragha — tumia tu kwa kumbukumbu binafsi kwenye kifaa chako.
